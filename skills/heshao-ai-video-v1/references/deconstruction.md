# 参考片拆解表 / Deconstruction

目标：把参考片拆成**可抽象的方法**和**禁止复制的具体表达**。拆完你应该能说出“它为什么有效”，而不是“它用了什么颜色”。

## 0. 先清点素材

| 项 | 有 | 没有时怎么办 |
|---|---|---|
| 成片 MP4 | 抽帧看构图、转场、字幕、音效落点 | 用工程文件重建；明确告诉用户“MP4 缺失，本次按工程拆解”，不要假装看过 |
| 工程 HTML/CSS/JS | 读场景、相机、时间轴 | 用旁白 + 时间轴 + 音效表重建 |
| 旁白 / 配音 | 听语速、句长、重音 | 只看文案，标注“语速未核” |
| 时间轴 / SFX 事件表 | 精确到秒的幕长、卡点 | 从视频抽帧估算，标注“估算” |
| 字体 / 音效 / 素材 | 记录是否可复用（通常不复用视觉素材） | 找同气质替代 |
| 播放数据 | 才能说“表现最好” | 没有数据就说“按结构与方法判断” |

## 1. 六张表

### A. 视觉

- 底色 / 主色 / 强调色 / 语义色；
- 字体：中文标题、英文/数字、正文、HUD；
- 材质：金属、纸、玻璃、钢、塑料、扫描线、颗粒；
- 光：方向、色温、体积光、光扫；
- 构图：画幅、主体位置、安全区、网格；
- 记忆点：观众看完能画出来的 1–2 个元素。

### B. 文案

逐句抄下来，标：

- 钩子类型（提问 / 损失 / 反差 / 倒计时 / 物件）；
- 卖点顺序（入口 → 搜索 → 安装 → 校验 → 广度 → CTA）；
- 句长（汉字数）、语气、是否押韵；
- 关键词字幕（不是逐句）；
- CTA 的动词与句式。

### C. 节奏

- 每幕起止、时长；
- 镜头任务（建立 / 演示 / 转折 / 落版）；
- 快慢曲线：哪几秒最密，哪几秒留白；
- hold：关键信息落定后停多久；
- 甩镜/推拉次数与前后静帧。

### D. 转场

逐一列：硬切、相机平移、推拉、光扫、半调擦除、闪白、遮罩、翻页、快门。记录**组合**，不只记录单个。

### E. 字幕

- 位置（中下 / 左下 / 左上 / 跟随主体）；
- 出现方式（逐字、遮罩、打印、盖章、弹入）；
- 关键词策略（每句几个字、是否独立色块）；
- 与旁白的关系（复读 / 补充 / 只留关键词）。

### F. 声音

- 旁白声线、语速、润音链；
- 有无 BGM；
- 音效名单、数量、密度、卡点；
- 转场音、动作音、落版音分别是什么。

## 2. 两列结论

| 可抽象（借） | 禁止复制（不借） |
|---|---|
| 强钩子 | 原句、句式、押韵、卖点排序 |
| 一个视觉世界 | 具体配色、字体组合、材质母题 |
| 真实操作 | 分镜序列、幕长组合、镜头路径 |
| 关键词字幕 | 字幕位置、出现方式、动效 |
| 动作音效 | 音效名单、卡点排列 |
| 高信息密度 | 转场组合、视觉母题 |
| 落版结构 | CTA 表达 |

## 3. Filled example：promo-kinetic（暖光动能）

> 4:3 / 1440×1080 / 30fps / 46.53s / 无 BGM / 15 句旁白 / 16 个音效文件、58 个事件 / Xiaoyi 女声
> 拆解依据：完整工程 + narration + timeline + SFX 表；成片 MP4 缺失。

**视觉**：深焦糖暗场 `#1A1207`；蜂蜜金金属字；蜜橘光扫；暖白正文；NotoSansSC 900 / Anton / Geist / Geist Mono；金属立体字、暖玻璃面板、角括号取景框、64px 网格、半调、颗粒、暗角；左上体积光 + 横向光带。

**文案**：钩子“装技能、找 MCP、约专家、淘插件，以前要开四个地方”；中段“四个市场共用一个搜索框 → 输入 PDF → 19 万+ 筛出 → 安装 → sha256 → 已安装 → 重装即更新”；广度“刚装的是哪张 / 哪个技能没人调用 / 换机器怎么搬”；落版“一条命令装好，完全退出再打开”。

**节奏**：m00 8.57s / m01 10.65s / m02 13.99s / m03 8.72s / m04 4.60s；单一相机、横向光带、长镜头连续运镜；无硬切；快速甩镜 ≤2 次；关键信息 hold ≥1s。

**转场**：相机缓动 + 上一幕淡出 + 暖光扫 / 半调擦除 / 闪白。

**字幕**：屏幕中下关键词贴纸，逐字点亮（clip-path 进度），非逐句。

**声音**：Xiaoyi 女声；无 BGM；riser / tick / slam / sweep / hit / shimmer / select / tap / scan / pop / type / success / chime / bell / zoom 等 16 个文件，58 个事件，按旁白重音与动作钉帧。

**它为什么有效**：

1. 第一句用“四个动作 + 四个地方”把入口焦虑具体化；
2. 全片只建立一个暖光金属世界，观众不用重新适应；
3. 中段用真实操作（输入、点、下载、校验、标已安装）建立可信度；
4. 字幕只留关键词，画面不被文字淹没；
5. 音效落在动作上，没有 BGM 也不空；
6. 结尾用一条命令完成行动号召。

**本片禁止借用的具体项**：所有原句、五幕序列与幕长、单一光带相机、暖光扫/半调/闪白、金属字砸落、取景框锁定、逐字点亮字幕、蜂蜜金/体积光/火星母题、16 类音效的名单与排列、模板代码的运动参数。

## 4. 输出模板

```md
# 参考片拆解 · <name>

## 一句话判断
<它为什么有效，不超过 80 字>

## 六张表
### 视觉
### 文案
### 节奏
### 转场
### 字幕
### 声音

## 可抽象 / 禁止复制
| 借 | 不借 |
|---|---|

## 本片必须避开的 5 个具体项
1.
2.
3.
4.
5.

## 缺失项
- 成片 MP4：有 / 无（无则说明按什么重建）
- 播放数据：有 / 无

```

拆完先让用户看这张表，再进入创意。不要跳过拆解直接画分镜。
