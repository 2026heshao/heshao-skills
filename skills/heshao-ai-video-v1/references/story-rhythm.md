# 产品片故事与节奏 / Story & Rhythm

本文件的幕长、口播占比、空白、关键词字幕与 CTA 是 `product_promo` 规则。纯动画故事、角色对白或无声表演先读 [动画流程](ai-animation-workflow.md)，按事件与表演节奏验收，不用语音占比判它失败。

## 1. 默认预算

- 时长：默认 **41s（5×8.2s）**；45s 只给信息层确实更厚的片子，30–60s 之间按内容定。
- 幕数：5–6 幕。
- 单幕：5–9s；最长不超过 10s。
- **1× 播放就必须是舒服的速度**，不许默认"用户会开倍速"。出片前量两个数：
  旁白占时比 = Σ(句长) / 成片时长 ≥ **0.80**；每幕最长空白（幕内既无旁白也无关键动作的最长连续段）
  ≤ **0.35s**，落版除 CTA hold 外 ≤ **1.0s**。不达标就压 `narration.json` 的 `gap_after`
  （默认 0.16–0.22）与幕间 `pad`，禁止用拉长镜头凑时长。
  2026-11-05 skilllocker 实测：旁白占时已达 87.2%（字数不缺），慢在幕间留白 0.45–0.50s 与
  落版空白 1.60s；按上面的默认值，同样文案能自然收到 42–43s。
- 旁白：10–15 句；每句 8–24 个汉字。
- 字幕：10–14 条关键词；每条 ≤ 16 个汉字。
- 画幅：4:3（1440×1080）优先；信息流另出 3:4，不裁切。

## 2. 钩子类型

| 类型 | 示例 | 适用 |
|---|---|---|
| 提问 | “给 AI 装了这么多，你还记得几件？” | 用户有失控/遗忘痛点 |
| 损失 | “有些技能，装完就再没被叫过。” | 工具/上下文成本 |
| 反差 | “四个地方，现在只剩一个入口。” | 入口分散 |
| 倒计时 | “三秒，找到上周装的那个。” | 搜索/召回 |
| 物件 | 一件货签/一张纸单从画面穿过 | 有强符号的产品 |
| 自白 | “我以前靠记忆管理插件。” | 个人化叙事 |

选参考片**没有用过**的钩子；不要只换名词。

## 3. 六幕骨架（盘点型）

| 幕 | 任务 | 旁白功能 | 画面功能 |
|---|---|---|---|
| 1 入库口 | 钩子 | 提出问题/损失 | 一个强符号 + 一个计数/对比 |
| 2 建账 | 命名 | 产品名 + 承诺 | 把四类东西收进一张单/一个台 |
| 3 翻账 | 证据 1 | 装于/来源/分类/最近 | 卡片、字段、排序、扫码 |
| 4 减重 | 证据 2 | 零调用/上下文税/禁用释放 | 表盘、行列、开关、印章 |
| 5 点名 | 证据 3 | 召唤菜单/套件/本项目 | 工具卷、插入 token、挂专家 |
| 6 入库 | 落版 | 价值句 + 命令 | 四货架、标题、命令、盖章 |

这不是唯一结构。装配型、救援型、对比型也可以，但每一幕只做一件事。

### 变体：星图救援型（atlas）

| 幕 | 时长 | 任务 |
|---|---:|---|
| 失联 | 6.72s | 倒计时钩子：找那个只记得一半名字的技能 |
| 星图 | 8.92s | 报名字 + 明说“比作星图” + 四类各有轨道 |
| 来路 | 5.42s | 星图是看法，账本记来路；最近安装 |
| 暗星 | 7.53s | 零调用/暗星；禁用/释放；上下文占用下降 |
| 牵引 | 10.09s | 套件、三条指令、召唤菜单、本项目 |
| 落版 | 8.30s | 价值句 + 命令 + 比喻脚注 |

总 46.98s。适合“能力很多、叫不出”的工具库；星图只做看法，不是产品功能。

## 4. 节奏曲线

```
0s        6s        13.7s     20.9s     27.8s     36.5s     44.9s
|--钩子---|--命名---|--证据 1--|--证据 2--|--证据 3--|--落版---|
  中密       蓄力       高密       峰值       高密       收束
```

- 密度不要平均：钩子 1 个强动作，证据段每 1.5–2s 一个动作，落版只做 3 件事（标题、价值句、命令）。
- 关键信息落定后 hold ≥ 0.8s；落版 CTA 单独按 ≥1.2s 要求。
- 落版先保 CTA：最后一句旁白结束前不要收光圈/淡出；命令完整可读 ≥1.2s。atlas 实测：光圈 45.05s 起收会压住最后一句；改到 45.80s 起收，最后一句 45.88s 结束时前 0.1s 仍接近全开，不压字。
- 硬切前后留 0.2–0.3s 呼吸；不要连续 3 个以上硬切无停顿。
- 快速甩镜/大幅位移全片 ≤ 2 次，前后留静帧。
- 留白有上限，不是"越多越从容"：幕间 ≤0.35s、落版除 CTA hold 外 ≤1.0s（见 §1 闸门）。
  时间不够就减信息层或减幕，不要靠空场撑。

## 6. 文案规则

- 一句只做一件事：问题、命名、证据、动作、结论。
- 少用形容词，多用动词和数字；数字必须有出处。
- 口播要像人在说话：短句、逗号多、少用书面连接词。
- 每句结尾尽量落在具体名词上，方便字幕取关键词。
- 不要把功能名堆成一句话；四类东西可以并列，但要给一个动作（“各占一行”“收进一张单”）。
- CTA 不要复用参考片动词；价值句 + 具体动作，或反过来。

### 口播归一化

- `MCP` → `M C P`；`DSH` → `D S H`；`sha256` → `sha 二五六`；`PDF` 可按字母读。
- 英文产品名保留原文，但送 TTS 时可拆字母。
- 数字用汉字读法（“十九万”），除非是命令/版本号。

## 7. 字幕规则

- 关键词，不是逐句复读。
- 一条字幕一个记忆点；关键词块可以独立色块。
- 位置固定；与画面主体保持安全距离；不要压产品 UI 的关键操作。
- 出现方式与视觉世界一致：打印/遮罩/盖章/打字；不要混用三种。
- 字幕开关必须能一键关闭，方便看画面。
