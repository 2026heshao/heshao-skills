# 视觉世界配方 / Visual Worlds

一个片子只建立**一个**世界。以下配方是起点，不是模板；选定后要把颜色、字体、材质、动效、字幕、声音全部统一。

机器可读版在 `decks/worlds.json`。新增世界时，必须同时补 `compatibility.json` 的允许组合和 `weights.json` 的初始权重，再跑 `pick.mjs --validate`。

## 选择方法

从三个来源找：

1. **产品名**：军械库 → 盘点台/钢箱；档案 → 卷宗；实验 → 台架；地图 → 塔台。
2. **用户动作**：装/卸 → 传送带/货架；找 → 扫描/索引；修 → 工作台；搬 → 箱/清单。
3. **情绪**：焦虑 → 夜班/警报；掌控 → 台账/印章；轻松 → 手账/贴纸。

一句话概念要能同时回答：第一眼看到什么、产品怎么被使用、为什么只适合这个产品。

## 1. 夜班盘点台 / Depot Night Shift

- **底色**：深墨绿 `#080d0a`；钢面 `#151f19`；骨白纸 `#f2ebdc`。
- **强调**：信号绿 `#c9f45b`（核验/在线）、警示橙 `#ff6a3d`（零调用/风险）、印章红 `#df4a33`。
- **字体**：中文 900 黑体；英文/数字 Geist；编号/字段 Geist Mono。
- **材质**：穿孔钢、条码、冲孔纸单、钢箱、红章、百叶快门。
- **动效**：传送带、纸单滑入、章体砸下、卡片磁吸、工具卷展开、箱盖翻开。
- **转场**：机械快门/闸门硬切；幕内 ±5px 冲击。
- **字幕**：左下入库标签 + 独立关键词块 + 条码。
- **声音**：继电器、扫码、印章、翻纸、磁吸、伺服、开关、打字、低频 thump。
- **适合**：工具库、插件市场、技能管理、库存/清单类产品。
- **避免**：不要和暖金/体积光/光带混用；不要用居中关键词贴纸。

## 2. 蓝图检修 / Blueprint Inspection

- **底色**：普鲁士蓝 `#071b2b`；纸白 `#f4f1e8`；钴蓝线 `#4d8dff`；朱砂 `#e5482f`。
- **字体**：工程手写体/等宽；中文黑体；尺寸标注用细等宽。
- **材质**：蓝图网格、尺寸线、剖切符号、铆钉、半透明描图纸。
- **动效**：线条描画、尺寸线收拢、剖切揭示、图章、翻图纸。
- **转场**：卷纸/折图/描线擦除。
- **字幕**：图纸标注式，贴在尺寸线旁。
- **声音**：铅笔、尺子、纸张、图章、低频。
- **适合**：开发工具、架构、工程化、安全审计。
- **避免**：不要做成“科技蓝 HUD”；蓝图要像纸，不像屏幕。

## 3. 塔台调度 / Control Tower

- **底色**：夜蓝 `#050b16`；雷达绿 `#7dffb2`；琥珀 `#ffb02e`；警示红。
- **字体**：等宽 + 窄体无衬线；数字大。
- **材质**：雷达环、跑道条、航班条、信号灯、玻璃。
- **动效**：雷达扫描、航班条滑入、灯闪烁、光点移动。
- **转场**：雷达扫过/信号切换/硬切。
- **字幕**：塔台通话条/航班条。
- **声音**：无线电报话、雷达脉冲、继电器、低频。
- **适合**：多市场/多入口调度、监控、路由、编排。
- **避免**：不要用真实航空代码/机场名；用抽象编号。

## 4. 档案卷宗 / Case File

- **底色**：旧纸 `#e8dfc8`；墨黑；档案红；牛皮纸棕。
- **字体**：打字机等宽 + 粗黑标题；印章体。
- **材质**：牛皮纸袋、绳扣、打孔、红章、照片角贴、索引卡。
- **动效**：抽卷宗、翻页、盖章、贴标签、打字。
- **转场**：合上卷宗/抽屉/盖章。
- **字幕**：索引卡/标签。
- **声音**：纸张、抽屉、打字机、章、绳扣。
- **适合**：专家/人设、知识库、合规、调查、版本历史。
- **避免**：不要做成“复古滤镜”；纸的质感要服务信息层级。

## 5. 实验台 / Lab Bench

- **底色**：冷白/浅灰；黑；实验蓝；荧光黄。
- **字体**：无衬线 + 等宽；标签小。
- **材质**：台面、试管、量筒、标签、夹子、网格垫。
- **动效**：滴管、液面、夹取、贴标签、测量。
- **转场**：推近/拉远/遮挡。
- **字幕**：实验记录条。
- **声音**：玻璃、滴液、夹子、离心机、低频。
- **适合**：AI 能力、测试、评测、数据、模型。
- **避免**：不要用真实化学危险符号；用抽象度量。

## 6. 野战手册 / Field Manual

- **底色**：卡其/橄榄；骨白；安全橙；钢灰。
- **字体**：模板字/窄体；编号；手写批注。
- **材质**：帆布、模板喷字、活页夹、地图、胶带、铆钉。
- **动效**：翻活页、拉地图、贴胶带、盖章、拉绳。
- **转场**：翻页/拉链/胶带撕开。
- **字幕**：手册页脚/编号标签。
- **声音**：帆布、拉链、胶带、章、低频。
- **适合**：部署、安装、迁移、现场操作、清单。
- **避免**：不要做“军事游戏 UI”；保持工具手册的克制。

## 7. 星图台 / Star Atlas

- **底色**：深靛夜空 `#05070f`；台面 `#0b1224`；纸白 `#f2eee2`。
- **强调**：星蓝 `#8fd8ff`（点亮/连线）、警示橙 `#ff7a4d`（缺口/零调用）、黄铜 `#d8a54a`（刻度/章记）。
- **字体**：中文 NotoSerifSC 600/900；英文/数字 Geist；编号/字段 Geist Mono。
- **材质**：星图版、黄铜子午环、星座连线、星等标签、光圈。
- **动效**：天空旋转、星点亮起、星座描线、光圈收放、日食擦除。
- **转场**：日食擦除 / 纯硬切（取自 `compatibility.json`，仅这两个）。
- **字幕**：左上图版题 / 页边注。
- **声音**：星图音 / 电子音。
- **可配钩子**：倒计时 / 反差 / 损失。**可配节奏**：救援 / 对比 / 一天。
- **适合**：能力地图、发现与检索、工具库、技能管理。
- **避免**：不要退回仓库/钢箱/传送带母题——它的 `bestFor` 与「夜班盘点台」高度重叠（工具库、技能管理），混用等于换色不换骨。
- **比喻合同**：星图是看法，不是功能。产品里没有星图时，第一次出现用“把 X 比作星图”，中段用“星图是看法，账本记来路”交回真实界面，落版/封面加脚注；不要写“把能力连成一张星图 / 星图就亮”。
- **风险**：牌组标记 `risk: medium`，原因即上述撞题；用于 dsh-armory 时必须先过 9 轴矩阵。atlas 的过闸方式：世界/转场/字幕/声音/CTA 全换，幕长有 3 幕与参考片差 >15%，不是换色。

## 统一规则

1. **一套世界**：颜色、字体、材质、动效、字幕、声音都从同一个隐喻长出来；不要混两个世界。
2. **4:3 构图**：主体在安全区内；固定舞台或单一相机二选一；不要从 16:9 裁切。
3. **3 层上限**：背景/主体/信息层；同屏卡片不超过 3 张。
4. **记忆点 1–2 个**：观众能画出来的东西（红章、货签、钢箱、雷达、蓝图线）。
5. **不与参考片同母题**：参考片用金属/光带，你就用纸/钢箱/章；参考片用 HUD，你就用纸单/标签。
6. **不与自己上一支片子同皮肤**：每支片子换世界，只复用工程管线。

## Filled example：depot

- 产品名“军械库” → 夜班盘点台。
- 用户动作“装/找/禁用/召唤” → 传送带/卡片/开关/工具卷。
- 情绪“东西太多、记不住” → 夜班、条码、0 次调用、红章。
- 记忆点：货签、红章“入库”、四只钢箱。
- 转场：百叶快门；字幕：左下入库标签；声音：机械音。
- 与参考片差异：暖金 → 骨白/钢绿；光带 → 固定台；逐字点亮 → 打印式标签；riser/whoosh → 继电器/印章/伺服。
