## 3. 从产品功能到实物道具：这次真正的设计方法

这次能成立，不是因为“暗夜 + 黄铜”好看，而是因为**每个产品功能都找到了一件实物**。

| 产品事实 | 实物道具 | 画面动作 | 旁白 |
|---|---|---|---|
| 技能看板：每个技能一张卡 | 卡片目录柜的抽屉 | 拉开抽屉，卡片躺在黑绒上 | 军械库，给每一件装备，留一个抽屉 |
| 收藏：右键/星标，最多 20 个，最近在前 | 黄铜星标 + 卡面“已收藏 · 最近在前” | 星标落下、旋转、压亮 | 常用的，钉一枚星标，让它一直亮着 |
| 搜索：按名称/描述筛选 | 索引台 + 呼号单 | 在纸片上打 `pdf`，抽出 `/pdf-kit` 卡 | 下次要用，搜两个字，或者叫出名字 |
| 零调用账本：注册但一次没被调用 | 旧纸标签 `/pdf-kit · 0 次调用 · 示例` | 标签落在暗厅，没被点亮 | 有些装备，装进来，就再没亮过 |
| 安装命令 + 重启 | 落版命令行 | 逐字打出 `dsh plugin --profile web add dsh-armory` | 一条命令，把军械库装进 DSH，重启就能用 |
| 全局面板入口 | 片尾小字“全局面板里多出「大肥鱼军械库」” | 落版副行 | 不喊口号，回到真实入口 |

关键动作：

- **不是“点面板”，而是“拉抽屉 / 钉星标 / 打字 / 抽卡”。** 观众看到的是手和物件，不是鼠标和 UI。
- **文字写在实物表面上。** 纸标签、黄铜卡、呼号单、落版排版；AI 图里没有任何文字。
- **产品名词在片尾收回。** “抽屉”是视觉比喻，片尾用真实面板名与安装命令收回，不声称产品里有木抽屉。
- **演示数据必须自曝。** `/pdf-kit` 是示例技能；“0 次调用”在标签和片尾都标“示例 / 演示数据”。

一句话概念：

> 夜班档案馆里，每一件装过的装备都有一个抽屉；常用的钉一枚黄铜星标，下次搜两个字或叫出名字就能用。

它同时回答三个问题：

1. 第一眼看到什么？—— 夜色里的档案馆、成排抽屉、黄铜拉手、一束暖光。
2. 产品怎么被使用？—— 拉开抽屉、钉星标、在索引台打字、抽出卡片。
3. 为什么只适合这个产品？—— 技能看板/收藏/搜索/零调用账本，正好对应抽屉/星标/呼号单/没亮的标签。

| 道具 | 做法 | 尺寸 / 位置 |

星标是这次最容易被看成“贴纸”的件：第一版是细线星，第二版是淡金平面星，最后改成**分面金属 + 中心铆钉 + 两层投影**才像实物。规则：**小图标要当实物做，不要当 icon 做。**

### 4.5 光、颗粒、转场

- 暖光漏光：`#leak` 用径向暖光 + 像素位移，转场时 0.7s 扫过；不做闪白。
- 颗粒：`#grain` 透明度 0.13，overlay；不盖字。
- 暗角：`#vig` 径向压暗；落版更重。
- 尘埃：canvas 每帧由 `t` 推导，不读随机数；颗粒/尘埃都进 `signature()`。
- 转场：暖光漏光 + 硬切；不做百叶、不做闪白、不做参考片的 riser/whoosh。

### 4.6 字幕

- 左下角，固定 `left:84px; bottom:78px`；编号 `01 / 07` + 关键词。
- 字幕是关键词，不是逐句复读；关键词用黄铜色 + 下划线。
- s04 落版不显示字幕，标题本身就是那句话；片尾命令/品牌/版本另排。
- 字幕窗口来自 `build_timeline.py`，不手写死。

## 6. 声音与“配音有杂音”修复

### 6.1 旁白

- Edge TTS `zh-CN-YunjianNeural`，男声；逐句 rate `-6%` / `-7%`，pitch `-1Hz` / `-2Hz`。
- lead 0.6s，tail 1.2s；7 句；无 BGM。
- 口播把 `DSH` 归一成 `D S H`，避免读成英文整词。

### 6.2 音效

23 个音效事件：7 个低频 sub + 纸、继电器、伺服、木箱、图章、打字。无参考片音源；全部 numpy 自产。

### 6.3 用户说“配音有杂音”时怎么量

先量旁白本身：

- 句间是数字零（-180 dBFS），不是底噪；
- 逐声道 0 削顶；
- 句首/句尾 10ms 最大跳变 0.001，不是咔哒；
- 4–8kHz 能量 2–13%，没有失控齿音；
- `voice_vault.wav` 与 `voice_vault.m4a` 的 mean/max 一致（-20.5 / -4.1 dBFS），不是编码问题。

再量混音句间，找到真正来源：

| 句间窗口 | 旧混音 RMS | 主要频率 | 判断 |
|---|---:|---|---|
| 3.72–3.92 | -42.0 dBFS | 90Hz + 45Hz | 持续房间底噪的嗡声 |
| 22.09–22.31 | -43.4 dBFS | 90.9Hz + 45.5Hz | 同上 |
| 10.19–10.39 | -28.4 dBFS | 55Hz | sub 尾巴，偏大 |
| 27.30–27.70 | -57.8 dBFS | 90Hz | 底噪收尾 |

结论：**旁白干净，噪声来自 28.2s 房间底噪（棕噪 + 45/90Hz）和过近的机械音效。** 不是 TTS 齿音，也不是 AAC。

### 6.4 修法

1. **整条删除房间底噪**（`name: "room"` 从 `film.json` 的 sfx 表移除）；句间回到数字零。
2. SFX 母线 `0.9 → 0.82`；纸/继电器/伺服/木箱再降 3–6 dB；sub `0.5 → 0.24`。
3. 保留图章、打字、纸卡等必要动作音；机械音效现在比旁白低 12–16 dB。
